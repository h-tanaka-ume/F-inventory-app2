# かんたん在庫管理アプリ（localStorage版）

GitHub Pagesで公開できる、ブラウザだけで動く在庫管理アプリです。外部データベースやログイン機能は使用しません。

## 機能

- 在庫一覧：品番・品名・保管場所・在庫数・発注点・状態
- 在庫一覧の検索・絞り込み：フリーワード、保管場所、在庫状態
- 要補充一覧：在庫数が発注点以下の商品を自動抽出
- 入出庫フォーム：入庫／出庫、数量、担当者、メモ
- 入出庫履歴：日時・種別・数量・担当者・メモ
- 商品ごとの削除と全商品の一括削除
- 品番自動生成：接頭辞＋ゼロ埋め連番（例：ITEM-0001）
- 品番の手入力への切り替えと重複チェック
- CSVインポート／エクスポート

## GitHub Pagesで公開する手順（ブラウザのみ）

1. GitHubにログインし、右上の`+`→`New repository`を開きます。
2. Repository nameに例として`inventory-app`と入力し、`Public`を選択して`Create repository`を押します。
3. 解凍したフォルダから`index.html`、`app.js`、`style.css`、`README.md`をリポジトリ直下へアップロードします。
4. `Commit changes`を押して保存します。
5. リポジトリの`Settings`→左メニューの`Pages`を開きます。
6. `Build and deployment`の`Source`を`Deploy from a branch`にし、Branchを`main`、フォルダを`/(root)`にして`Save`を押します。
7. Pages画面に表示されるURL（通常は`https://ユーザー名.github.io/inventory-app/`）を開きます。

## データ保存について

- データは利用したブラウザの`localStorage`に保存されます。
- 別のパソコン、スマートフォン、ブラウザとは共有・自動同期されません。
- ブラウザのサイトデータを削除すると、保存データも消える可能性があります。
- 端末変更や定期バックアップのため、右上の`CSVエクスポート`を利用してください。
- 別の端末で復元するときは`CSVインポート`を利用してください。
- 共有データベース、ログイン、複数人同時利用が必要な場合は、別途FirebaseやSupabaseなどのバックエンド連携が必要です。
